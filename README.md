# 🔐 Password Security Checker

A Python-based cybersecurity tool that analyzes the strength and security of a password.

## 🚀 Features

* Password length analysis
* Uppercase letter detection
* Lowercase letter detection
* Number detection
* Special character detection
* Common password detection
* Repeated character detection
* Sequential pattern detection
* Security score from 0–100
* Password strength classification
* Security improvement suggestions
* Estimated password entropy
* Hidden password input for better privacy

## 🛠️ Technologies Used

* Python 3
* Regular Expressions (`re`)
* Math (`math`)
* GetPass (`getpass`)

## ▶️ How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code or a terminal.
4. Run:

```bash
python password_checker.py
```

5. Enter a password when prompted.

## 📊 Password Strength Levels

| Score  | Strength    |
| ------ | ----------- |
| 0–29   | Very Weak   |
| 30–49  | Weak        |
| 50–69  | Medium      |
| 70–89  | Strong      |
| 90–100 | Very Strong |

## ⚠️ Disclaimer

This project is created for educational and cybersecurity learning purposes. It is a basic password-strength analysis tool and should not be considered a complete password security solution.
